# GrantOnce 三分鐘畫面腳本

螢幕錄影。只點畫面，不切投影片。鏡頭從頭到尾停在應用程式。

開頭定格口號，結尾定格稽核時間線。總長 3–5 分鐘。

準備：`npm run dev` → 開 `http://127.0.0.1:43127` → 視窗拉到能看見三欄 → 按「重設演示」。

---

## 0:00–0:20　口號

鏡頭停在標題列。

畫面要看得見：

**GrantOnce 分匣授權**
**只准這一次，而且只准這一匣。**

不要講話超過兩句。然後往下移到左欄。

## 0:20–0:50　一句話

1. 點左欄大按鈕「演示這句：我剛搬家，看我能申請什麼。」
2. 停住，讓中欄出現兩個申請：育兒津貼、冷氣汰換。
3. 指一下「孩子滿 2 歲後條件會改變」。

不要再打字。

## 0:50–1:40　兩匣，分別核准

1. 左欄出現 G-甲、G-乙。
2. 先點 G-甲「核准這一匣」。
3. 再點 G-乙「核准這一匣」。
4. 鏡頭移到右欄：甲是戶籍＋親子，乙是電號＋用電。
5. 指左欄金庫：所得是「封存 · 不授權」。右欄兩匣都沒有所得。

不要按任何「全部交出」——畫面上沒有那顆按鈕。

## 1:40–2:20　乙越權

1. 在機關乙點「索取戶籍謄本」。
2. 停在紅字 **403**。
3. 乙的匣仍只有台電欄位，戶籍沒進去。

## 2:20–3:10　送件即撤

1. 在機關甲點「送出申請」。
2. G-甲變成已耗用。
3. 點「重放擷取」。
4. 再一個 403。

## 3:10–3:50　時間線收尾

鏡頭拉到右欄底部「稽核時間線」。

要看得到這五種戳記：

核准　擷取　送件　撤銷　拒絕

定格三秒。結束。

---

## 不要入鏡

- 真實個資、真實 MyData、真實送件（本演示全是合成）
- 投影片、講者切鏡、剪輯花字蓋過口號
- 解釋程式碼；那是簡報第 8 頁的事，這支影片只點畫面
